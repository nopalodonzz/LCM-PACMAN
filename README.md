# LCM QUEST — Kembara Pokok Faktor & GSTK

Permainan pendidikan Matematik berasaskan Pac-Man untuk latihan faktor perdana dan GSTK (Gandaan Sepunya Terkecil).

## Kandungan
- `index.html` — permainan lengkap; CSS dan JavaScript berada dalam fail ini.
- `.nojekyll` — memastikan GitHub Pages menerbitkan fail statik tanpa pemprosesan Jekyll.

## Terbitkan menggunakan GitHub Pages

1. Log masuk ke GitHub dan cipta repositori baharu.
2. Muat naik `index.html`, `README.md` dan `.nojekyll` ke **root** repositori.
3. Buka **Settings → Pages**.
4. Di bawah **Build and deployment**, pilih **Deploy from a branch**.
5. Pilih branch `main` dan folder `/(root)`, kemudian tekan **Save**.
6. Tunggu proses penerbitan selesai. Pautan laman akan dipaparkan pada halaman Settings → Pages.

## Cara bermain
- Buka laman dan tekan butang mula.
- Gunakan kekunci anak panah atau WASD pada komputer.
- Pada telefon, gunakan butang arah di bawah maze.
- Kumpul nombor faktor perdana untuk melengkapkan pokok faktor, kemudian jawab soalan GSTK.

## Nota
- Permainan ini menggunakan HTML, CSS, JavaScript dan Canvas; tiada proses build atau pemasangan diperlukan.
- Fon Google Fonts memerlukan sambungan internet. Permainan masih mempunyai fon sandaran jika fon luaran tidak tersedia.
